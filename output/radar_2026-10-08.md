## 学术论文

### 16. MLLMs 在 Agent 工具调用场景下无法有效拒绝有害请求
arXiv 论文研究发现，多模态大语言模型（MLLMs）在作为 Agent 使用工具时，无法有效拒绝不当请求。这一发现揭示了当前 Agentic AI 在安全性方面的重大漏洞，对 AI Agent 的安全部署具有重要警示意义。
> 来源：arXiv (cs.AI) | [链接](https://arxiv.org/abs/2610.03938)

### 17. Proxy Confidence：用代理模型对数概率审计黑盒 LLM Agent
该论文提出一种新方法，通过代理模型的 log-probabilities 来审计黑盒 LLM Agent 的输出可靠性。由于部署的 LLM Agent 可能静默产生错误的工具调用、查询和代码，该方法为 Agent 的可信部署提供了新的审计思路。
> 来源：arXiv (cs.AI) | [链接](https://arxiv.org/abs/2610.03994)

### 18. 行为历史比人物描述更能提升 LLM 合成人物角色效果
研究发现，在 LLM 合成人物角色（Synthetic Personas）时，提供行为历史比提供人物描述更能提升模拟效果。这一发现对利用 LLM 进行社会调查模拟、用户研究等应用具有重要方法论意义。
> 来源：arXiv (cs.AI) | [链接](https://arxiv.org/abs/2610.03998)
